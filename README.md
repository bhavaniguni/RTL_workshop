# [RTL Design and Synthesis Workshop](https://www.vlsisystemdesign.com/rtl-design-using-verilog-with-sky130-technology/)


Welcome to the **RTL Design and Synthesis Workshop**, a hands-on learning journey focused on **Verilog RTL Design**, **Simulation**, **Synthesis**, and **Digital Design Optimization** using open-source EDA tools.

## 📚 Workshop Overview

This repository contains day-wise notes, RTL codes, simulation results, synthesis outputs, and practical labs covering:

- Verilog RTL Design
- RTL Simulation using Icarus Verilog
- Waveform Analysis using GTKWave
- Logic Synthesis using Yosys
- SKY130 Standard Cell Libraries
- Gate-Level Simulation (GLS)
- Timing Libraries and Flip-Flop Coding
- Combinational and Sequential Optimization
- Synthesis Optimization Techniques

## 📅 Workshop Structure

- **Day 1:** Introduction to Verilog RTL Design & Synthesis
- **Day 2:** Timing Libraries, Synthesis Approaches, and Efficient Flip-Flop Coding
- **Day 3:** Combinational and Sequential Optimization
- **Day 4:** Gate-Level Simulation (GLS), Blocking vs Non-Blocking Assignments, and Synthesis-Simulation Mismatch
- **Day 5:** Optimization in Synthesis

## 🛠️ Tools Used

- Icarus Verilog (iverilog)
- GTKWave
- Yosys
- SKY130 PDK
